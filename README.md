# 🌤️ Weather App

A simple and responsive Weather App built using HTML, CSS, and JavaScript.

The application allows users to search for a city and view basic weather
information such as temperature, weather condition, humidity, and wind speed.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Display temperature
- ☁️ Display weather condition
- 💧 Display humidity
- 💨 Display wind speed
- 📱 Responsive design
- 🎨 Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🌍 Available Cities

The current demo includes weather data for:

- New Delhi
- Mumbai
- Jaipur
- Amritsar

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `Weather-App` folder.
3. Open `index.html` in a web browser.
4. Enter a supported city name.
5. Click the Search button.
